## Introducing Today's Project!

In this project, we are setting up our own Personal Amazon Web Services (AWS) Account.

### Key tools and concepts

The tools I used were the AWS Dashboard, Billing Alerts, and MFA authentication through another device.

### Challenges and wins

This project took me approximately 1 hour and 30 minutes. While there were no particularly challenging parts, I did encounter some confusing steps, such as creating the account.

---

## Creating My AWS Account

In this step I will:

1. Create a personal AWS account.
2. Verify the account using my email.
3. Set a strong password and enable multi‑factor authentication using my other device.

### Understanding the root user

I learned that a root user is the account I personally set up.  
I learned that a strong, secure password is essential for account security.

---

## Setting Up Billing and Payment

In this step I will:

1. Set up billing and choose an account plan.

2. Enter my account and contact information.

3. Configure my payment method.

### Why AWS requires a payment method

Even if I set up my account on the AWS Free Tier, AWS still provides access to more than 30 services. This monitoring helps prevent fraud and improves security by tracking daily usage to detect potential abuse.

---

## Completing Account Activation

In this step I will:

1. Confirm my identity to complete account creation.

2. Select the Free Tier support plan.

### Identity verification and support plan

I verified my identity by confirming the email I used to create my AWS account.  
I enabled multi‑factor authentication (MFA) and other security measures to protect my account, and I selected the Basic Support plan.  
The Basic Support plan includes user resources such as AWS Documentation and AWS Trusted Advisor.

---

## Enabling Free Tier Alerts

In this step I will enable the Free Tier usage alert by navigating to Billing Preferences.

![Image](http://nextwork.ai/genuine_orange_serene_turtle/uploads/aws-account-setup_j6k1l7m3)

### Why usage alerts matter

I set up usage alerts to monitor my credits — both how many I have and how much I use.

---

## Securing the Account with MFA

I use the Microsoft Authenticator app on my phone to enable two‑factor authentication (MFA). This adds an extra layer of security, acting like a second password or passcode for my account.
